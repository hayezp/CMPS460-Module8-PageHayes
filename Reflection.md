# Module 8 Assignment Reflection

For this assignment, I created a Personal Mobile Organizer app using React Native, Expo, and TypeScript. I started with the task manager we made for the Module 8 lab and added more features to turn it into a more complete app. The main goal was to make something simple that people could actually use to keep track of their tasks.

I added a Settings screen and used bottom tabs so users could switch between the different screens. I also made it so users could add tasks, edit them, view their details, and delete them. One thing I thought was pretty useful was adding a confirmation before deleting a task, just so someone doesn't accidentally delete something they wanted to keep.

I also used AsyncStorage to save the tasks. I tested it by reloading the app to make sure everything was still there, and it worked. I added messages for when tasks are saved, when something goes wrong, and when the app is loading.

The hardest part for me was figuring out where certain pieces of code needed to go. A few times I put something in the wrong spot or missed a comma, which caused errors. It was frustrating at times, but once I figured out what was wrong, everything started working again.

Overall, I feel like I understand React Native a little better now. I'm getting more comfortable working with different screens, fixing errors, and seeing how everything comes together to make an actual app.
